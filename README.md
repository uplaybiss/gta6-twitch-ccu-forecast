A deterministic Python 3.13 forecast of GTA VI Twitch viewers. It picks 12 comparable launch days by first-hour audience, estimates quantiles from their hourly log ratios, and rescales them to the observed first hour.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3.13 -P -s main.py
```
